# 期刊风格库 (Journal Style Database)

> 流水线启动时加载此文件，根据论文主题自动匹配最适配的目标期刊风格。
> 每个期刊条目包含：领域标签、摘要要求、关键词数量、参考文献要求、篇幅建议、特殊格式要求。

---

## 匹配规则

1. 从论文主题提取 2-4 个核心学科关键词
2. 在下方期刊条目的「领域标签」中匹配
3. 匹配度 = 命中标签数 / 主题关键词数
4. 取匹配度最高的 2-3 个推荐给用户

## 使用方式

流水线加载此文件后：

1. 从用户主题中提取学科关键词
2. 遍历上方期刊条目，计算领域标签匹配度
3. 向用户展示推荐结果，格式如下：

```
根据您的论文主题，推荐以下目标期刊风格：

1. 《XXX学报》（匹配度: 高）
   - 侧重：XXX
   - 摘要：XXX字
   - 综述篇幅：XX-XX页

2. 《XXX学报》（匹配度: 中）
   - 侧重：XXX
   - 摘要：XXX字
   - 综述篇幅：XX-XX页

请选择目标风格，或输入您指定的期刊名称。
```

4. 用户确认后，将该期刊的全部风格参数注入 S2（写作）和 S6（格式检查）阶段
