# 提交就绪判定标准 (Final Verdict)

> 用于 S3 论文自审阶段的最终裁定。
> 在 7 步审查全部完成后，综合所有问题分级，给出论文的整体提交就绪判定。

---

## 判定流程

1. 汇总 Step 1–7 检出的全部问题，按 P0 / P1 / P2 分级统计。
2. 逐项核对下方「阻断条件」。
3. 根据阻断条件命中情况，输出最终 Verdict。

---

## 问题分级定义

| 级别 | 标签 | 含义 | 处理要求 |
|------|------|------|---------|
| P0 | 🔴 阻断 | 严重影响论文学术可信度或结构完整性 | **提交前必须解决** |
| P1 | 🟡 应改 | 影响论文质量但不致命 | 本周内修改 |
| P2 | 🔵 优化 | 可提升可读性或规范性 | 提交前尽量处理 |

---

## 典型 P0 阻断问题

以下任一情况出现即判定为 P0：

- Claim Audit 中存在 ≥1 项 `remove` 判定（过度主张未修正）
- Claim Audit 中存在 ≥2 项 `revise` 判定且未修改
- 文内引用编号与参考文献表不对应（断链）
- 缺少对比表格（综述类型要求 ≥1 张）
- 参考文献格式全文不统一
- 章节结构严重残缺（缺少核心章节）
- 摘要中引用了图表编号或参考文献编号
- 引言编号不为 "0"

## 典型 P1 应改问题

- 结论未回扣正文具体章节
- 英文摘要或关键词缺失
- 子节篇幅严重不均衡（相邻子节字数差 >50%）
- 某技术维度缺少代表性文献
- 笔误或术语前后不一致
- 参考文献著录项信息不完整

## 典型 P2 优化问题

- 长句 (>100 字) 未拆分
- 高频连接词 ("此外"/"然而") 过多
- 段落节奏单一（连续三句长度相同）
- 表格标题格式微调
- 摘要字数轻微超标

---

## Verdict 判定矩阵

| Verdict | 条件 |
|---------|------|
| ✅ `ready with minor edits` | P0 = 0 且 P1 ≤ 2 且 P2 ≤ 5 |
| ⚠️ `needs moderate revision` | P0 = 0 且 (P1 > 2 或 P2 > 5) |
| ❌ `not ready` | P0 ≥ 1 |

### 判定逻辑

```
IF count(P0) >= 1:
    Verdict = "not ready"
ELIF count(P1) <= 2 AND count(P2) <= 5:
    Verdict = "ready with minor edits"
ELSE:
    Verdict = "needs moderate revision"
```


---

## 特殊情况处理

### Claim Audit 全 keep
若全部主张均判定为 `keep`，仍需检查其余维度。Claim Audit 通过不等于论文就绪。

### 引用断链
文内引用与文献表不对应属于 P0 阻断。若仅 1 处断链，修复后可降级为 P1。

### 表格缺失
综述类型论文要求 ≥1 张对比表格嵌入正文。若完全缺失，属于 P0；若数量不足但有，属于 P1。

### 字数轻微偏差
总字数在 8,000–10,000 之间为 P1，低于 8,000 为 P0（需大幅补写）。
