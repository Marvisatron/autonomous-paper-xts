# GB/T 7713.2-2022 规则库

> 基于 GB/T 7713.2-2022《科学技术报告、学位论文和学术论文的编写格式》
> 用于 S6 格式合规检查阶段。共 19 大类，逐项检查。

---

## A. 结构完整性 (A01–A08)

| 编号 | 检查项 | 规则 | 严重级别 |
|------|--------|------|---------|
| A01 | 题名 | 必须存在，位于首页显著位置 | ERROR |
| A02 | 作者信息 | 必须存在（姓名、单位、通信方式），可含占位符 | ERROR |
| A03 | 摘要 | 必须同时包含中文摘要和英文摘要 | ERROR |
| A04 | 关键词 | 中英文关键词均必须存在 | ERROR |
| A05 | 引言 | 必须存在，编号为 "0" | ERROR |
| A06 | 正文 | 必须包含 ≥1 个有编号的章节 | ERROR |
| A07 | 结论 | 必须存在独立结论章节 | ERROR |
| A08 | 参考文献 | 必须存在，置于正文之后 | ERROR |

---

## B. 前置部分 (B01–B08)

| 编号 | 检查项 | 规则 | 严重级别 |
|------|--------|------|---------|
| B01 | 题名长度 | ≤ 25 个汉字（含标点），确需超过时可用副题名 | WARNING |
| B02 | 题名用语 | 使用规范术语，避免缩写、公式、商品名 | WARNING |
| B03 | 中文摘要字数 | 报道性摘要 ~400 字 / 指示性摘要 ~150 字 / 报道-指示性 ~300 字 | WARNING |
| B04 | 英文摘要 | 与中文摘要内容对应，语法正确 | WARNING |
| B05 | 摘要内容 | 不含图表编号、数学式、参考文献编号 | ERROR |
| B06 | 摘要结构 | 不使用 Background/Methods/Results/Conclusions 标签，写为自然段落 | WARNING |
| B07 | 关键词数量 | 3–8 个 | ERROR |
| B08 | 关键词格式 | 词间用分号（中文）或逗号（英文）分隔，末尾无标点 | WARNING |

---

## C. 正文编排 (C01–C10)

| 编号 | 检查项 | 规则 | 严重级别 |
|------|--------|------|---------|
| C01 | 引言编号 | 引言章节编号必须为 "0" | ERROR |
| C02 | 章节编号层级 | ≤ 4 级（如 1.2.3.4），不得更深 | ERROR |
| C03 | 编号格式 | 阿拉伯数字 + 下圆点（如 1.2.3），末级编号后无圆点 | ERROR |
| C04 | 标题长度 | 每级标题 ≤ 15 个汉字 | WARNING |
| C05 | 标题末尾标点 | 各级标题末尾不得有标点符号（句号、逗号、问号等） | ERROR |
| C06 | 标题大写 | 中文标题不涉及大小写；英文标题首词首字母大写，其余按规则 | INFO |
| C07 | 子节均衡 | 同一层级子节篇幅不宜悬殊（建议相差不超过 50%） | INFO |
| C08 | 段落完整性 | 每段 3–8 句，有主题句和过渡 | INFO |
| C09 | Bullet point | 正文中不得出现 bullet point（列表项应转化为编号段落或自然段落） | ERROR |
| C10 | 章节连续性 | 章节编号必须连续，不得跳号 | ERROR |

---

## D. 技术与计量 (D01–D10)

| 编号 | 检查项 | 规则 | 严重级别 |
|------|--------|------|---------|
| D01 | 量和单位 | 使用法定计量单位（SI 制），量符号用斜体，单位符号用正体 | WARNING |
| D02 | 量符号首次出现 | 首次出现时给出全称和符号定义 | WARNING |
| D03 | 插图编号 | 全文连续编号（图 1、图 2……），不得断号 | ERROR |
| D04 | 插图标题 | 每张图必须有图号和图题，置于图下方 | ERROR |
| D05 | 表格编号 | 全文连续编号（表 1、表 2……），不得断号 | ERROR |
| D06 | 表格标题 | 每张表必须有表号和表题，置于表上方 | ERROR |
| D07 | 表注 | 表中缩写或符号需在表注中说明 | WARNING |
| D08 | 数学式编号 | 重要公式右侧编号（用圆括号），全文连续 | WARNING |
| D09 | 数字用法 | 按 GB/T 15835 执行：统计数用阿拉伯数字，惯用语用汉字数字 | WARNING |
| D10 | 表头格式 | 表头不使用斜线分隔，推荐三线表格式 | INFO |

---

## E. 参考文献 (E01–E08)

| 编号 | 检查项 | 规则 | 严重级别 |
|------|--------|------|---------|
| E01 | 引用体系 | 全文统一使用一种引用体系（顺序编码制 或 著者-出版年制） | ERROR |
| E02 | 文内引用编号 | 方括号内阿拉伯数字，按首次出现顺序编号 [1][2][3]… | ERROR |
| E03 | 文内-文献表对应 | 文内每个引用编号必须在文献表中有对应条目，反之亦然 | ERROR |
| E04 | 文献类型标识 | 每条参考文献必须标注类型标识：[J]期刊 [C]会议 [M]专著 [D]学位论文 [R]报告 [EB]电子资源 [N]报纸 | WARNING |
| E05 | 著录项完整性 | 期刊: 作者.题名[J].刊名,年,卷(期):页码. 专著: 作者.题名[M].出版地:出版者,年:页码. | WARNING |
| E06 | 作者著录 | ≤3 人全列，>3 人列前 3 人后加 "等" 或 "et al" | WARNING |
| E07 | 刊名 | 使用标准刊名全称，不缩写 | WARNING |
| E08 | DOI | 鼓励标注 DOI，in-press 文献标注 [DOI待核实] | INFO |

---

## F. 术语与语言 (F01–F08)

| 编号 | 检查项 | 规则 | 严重级别 |
|------|--------|------|---------|
| F01 | 术语规范 | 科技名词使用全国科学技术名词审定委员会公布的规范名词 | WARNING |
| F02 | 术语一致性 | 同一概念全文使用同一术语，不得混用 | ERROR |
| F03 | 缩写首次出现 | 缩写首次出现时给出全称（中英文均可） | WARNING |
| F04 | 标点符号 | 按 GB/T 15834 执行：中文语境用中文标点，英文语境用英文标点 | WARNING |
| F05 | 连接号 | 数值范围用波浪号 "~" 或一字线 "—"，不用短横线 "-" | WARNING |
| F06 | 百分号 | "百分之几" 用 "%"，不用 "个百分点" 与 "%" 混用 | INFO |
| F07 | 年代表述 | "20世纪" 而非 "二十世纪"；"2024年" 而非 "二〇二四年" | WARNING |
| F08 | 外文拼写 | 外文人名、地名、术语拼写正确，首次出现附中文译名 | WARNING |

## G. 篇幅与均衡 (G01–G04)

| 编号 | 检查项 | 规则 | 严重级别 |
|------|--------|------|---------|
| G01 | 总字数 | 综述 ≥ 10,000 字，研究论文 ≥ 6,000 字 | WARNING |
| G02 | 参考文献数量 | ≥ 25 条 | WARNING |
| G03 | 对比表格 | 综述类型 ≥ 1 张嵌入正文的对比表格 | ERROR |
| G04 | 中英文摘要对应 | 英文摘要应覆盖中文摘要的核心内容 | WARNING |

## H. 特殊格式 (H01–H04)

| 编号 | 检查项 | 规则 | 严重级别 |
|------|--------|------|---------|
| H01 | 收稿日期 | 格式：收稿日期：YYYY-MM-DD（可含占位符） | INFO |
| H02 | 基金项目 | 如有，置于首页脚注或文末致谢前 | INFO |
| H03 | 通信作者 | 标注通信作者及联系方式（可含占位符） | INFO |
| H04 | 致谢 | 如有，置于结论与参考文献之间 | INFO |

---

## 检查执行顺序

按 A → B → C → D → E → F → G → H 顺序逐类检查。

每类检查完毕后输出该类结果，标注：
- 🔴 ERROR: 必须修改，附具体位置和修改前后示例
- 🟡 WARNING: 建议修改，附具体位置和修改前后示例
- 🔵 INFO: 可选优化
- ✅ 已通过

全部类别检查完毕后汇总，进入自动修复环节。
