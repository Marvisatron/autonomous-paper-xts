# 逐节审查清单

> 用于 S3 论文自审阶段的逐节质量检查。

## 摘要
- [ ] 问题陈述清晰 (研究动机/领域现状)
- [ ] 方法/范围可识别 (综述方法、覆盖范围)
- [ ] 主要发现或贡献陈述
- [ ] 不含图表编号、数学式、参考文献编号
- [ ] 中英文摘要内容对应
- [ ] 摘要字数匹配类型: 报道性 ~400字 / 指示性 ~150字 / 报道-指示性 ~300字

## 0 引言
- [ ] 研究背景与动机 (为什么这个领域值得关注)
- [ ] 前人研究客观评介 (做什么了、什么还没做)
- [ ] 研究空白明确 (本文要填补什么缺口)
- [ ] 研究目标/问题陈述 (本文做什么)
- [ ] 论文组织结构导航 (各节内容预告)
- [ ] 引言编号为 "0"

## 基本原理 / 背景
- [ ] 核心概念定义清晰
- [ ] 关键公式符号说明完整
- [ ] 图示/表格辅助理解 (如有)
- [ ] 与后续章节的逻辑衔接

## 关键技术
- [ ] 每条技术路线有独立小节
- [ ] 技术原理说明足够本领域读者理解
- [ ] 关键参数和性能指标有具体数值
- [ ] 同一层次子节篇幅均衡 (相差不超过 50%)
- [ ] 有技术对比表格

## 应用场景
- [ ] 每个场景选型有代表性
- [ ] 具体案例支撑 (含参考文献)
- [ ] 定量数据支撑 (精度/准确率/成本等)
- [ ] 有跨场景对比表格

## 技术挑战
- [ ] 每个挑战有具体原因分析 (不只是罗列)
- [ ] 有当前解决方案的评述
- [ ] 技术层面 + 非技术层面兼顾

## 未来展望 / 发展趋势
- [ ] 趋势有技术依据 (不只是推测)
- [ ] 有具体技术路径和时间预估
- [ ] 与前面挑战章节相呼应

## 结论
- [ ] 不是摘要的简单重复
- [ ] 回扣正文各节的具体发现
- [ ] 每个结论可追溯到正文具体章节
- [ ] 客观、准确、精练
- [ ] 无新的引用或数据 (结论不引入新材料)

## 参考文献
- [ ] 文内引用与文献表一一对应
- [ ] 引用格式全文统一 (顺序编码制/著者-出版年制)
- [ ] 参考文献表置文末
- [ ] 每条著录项信息完整 (作者/标题/刊名/年/卷/期/页码)
- [ ] 文献类型标识齐全 ([J]/[C]/[M]/[D]/[EB] 等)
