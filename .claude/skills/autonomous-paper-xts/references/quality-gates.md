# 论文撰写流水线 —— 各阶段质量门

> 每个阶段完成后必须满足的最低质量标准。
> 不满足质量门的阶段不得进入下一阶段。

---

## S1 质量门：文献调研

| 指标 | 最低要求 | 理想目标 |
|------|---------|---------|
| 文献总数 | ≥ 25 篇 | 30-40 篇 |
| 英文文献占比 | ≥ 40% | 50-70% |
| 近 5 年文献 (2021-2026) | ≥ 60% | ≥ 75% |
| 覆盖技术维度 | ≥ 4 个 (原理/技术/应用/挑战) | 5 个 |
| 核心综述论文 | ≥ 3 篇 | 5-8 篇 |
| 中文核心期刊 | ≥ 2 篇 | 3-5 篇 |

**不通过处理**: 补充检索缺失维度，直到满足最低要求。

---

## S2 质量门：科学写作

| 指标 | 最低要求 | 理想目标 |
|------|---------|---------|
| 总字数 | ≥ 10,000 字 | 12,000-15,000 字 |
| 章节完整性 | 0引言 + ≥5章正文 + 结论 + 参考文献 | 完整 IMRaD 或综述结构 |
| 中英文摘要 | 均有 | 内容对应 |
| 关键词数量 | 3-8 个 | 5-6 个 |
| 参考文献条数 | ≥ 25 条 | 30-40 条 |
| 引用格式 | 全文统一编码制 | GB/T 7714 顺序编码制 |
| 章节编号 | ≤ 4 级，引言为 0 | 符合 GB/T 7713.2 |
| Bullet point | **0 处** | 0 处 |
| 对比表格 | ≥ 1 张 | ≥ 3 张 |

**不通过处理**: 补写缺失章节，删除 bullet point，添加表格。

---

## S3 质量门：论文自审

| 指标 | 最低要求 | 理想目标 |
|------|---------|---------|
| Claim Audit 覆盖 | 全部主要主张 (≥5项) | 逐段审计 |
| 引用完整性 | 文内引用与文献表一一对应 | 零断链 |
| 问题分级 | 明确 P0/P1/P2 分类 | 每项附修改建议 |
| 最终判定 | ready / needs revision / not ready | 明确分组 |

**不通过处理**: 补充缺失维度的审查，重新生成自审报告。

---

## S4 质量门：定向修改

| 指标 | 最低要求 | 理想目标 |
|------|---------|---------|
| P0 问题清零 | **0 项残留** | 0 项 |
| P1 问题清零 | ≤ 1 项残留 | 0 项 |
| P2 问题处理 | ≥ 50% 已修复 | ≥ 80% |
| 新增表格 | ≥ 3 张 | 3-5 张 |
| 参考文献格式统一 | 100% GB/T 7714 | 100% |
| 英文摘要 | 存在 | 与中文对应 |
| 结论回扣正文 | 每条结论可追溯到具体章节 | 明确对应 |

**不通过处理**: 修复剩余 P0/P1 问题后重新检查。

---

## S5 质量门：去AI痕迹

| 维度 | 最低分 (1-10) | 目标分 |
|------|-------------|--------|
| 直接性 | ≥ 6 | ≥ 8 |
| 节奏 | ≥ 6 | ≥ 7 |
| 信任度 | ≥ 6 | ≥ 8 |
| 真实性 | ≥ 5 | ≥ 7 |
| 精炼度 | ≥ 6 | ≥ 8 |
| **总分** | **≥ 35/50** | **≥ 40/50** |

**具体检测指标**:

| 模式 | 检出上限 |
|------|---------|
| 夸大意义/宣告 | ≤ 3 处残留 |
| "此外" | ≤ 2 处 |
| 破折号 (——) | ≤ 5 处/千字 |
| 三段式列举 | ≤ 3 处 |
| 填充短语 | ≤ 2 处 |
| 通用积极结论 | 0 处 |

**不通过处理**: 对未达标维度进行针对性重写。

---

## S6 质量门：格式合规

| 指标 | 最低要求 | 理想目标 |
|------|---------|---------|
| ERROR | **0 项** | 0 项 |
| WARNING | ≤ 3 项 | 0 项 |
| INFO | 不限 | 不限 |
| 题名 ≤ 25 字 | ✅ | ✅ |
| 作者信息 | 存在 (含占位符) | 完整 |
| 引言编号 | 0 | 0 |
| 章节编号格式 | 阿拉伯数字 + 下圆点 | 符合 |
| 标题末尾标点 | 无 | 无 |
| 表头无斜线 | ✅ | ✅ |
| 表格编号连续 | ✅ | ✅ |
| 参考文献著录 | GB/T 7714 格式 | 完整著录项 |

**不通过处理**: 逐项修复 ERROR 和 WARNING，重新检查至 ERROR=0。

---

## 最终交付判定

全部 6 个质量门均通过后，论文进入"可交付"状态：

| 版本 | 阶段 | 状态 |
|------|------|------|
| v1.0 | S2 完成后 | 初稿 |
| v2.0 | S4 完成后 | 自审修订版 |
| v3.0 | S5 完成后 | 人性化修订版 |
| v4.0 | S6 完成后 | **GB/T 7713.2 格式合规版 ← 最终交付** |
